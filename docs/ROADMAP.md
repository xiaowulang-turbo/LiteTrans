# LiteTrans 开发计划

## 当前状态：核心功能完成 (85%)

截图翻译核心流程已跑通，可通过 `npm run dev` 本地使用。

---

## 阶段一：发布准备 (P0)

| 任务 | 状态 | 说明 |
|------|------|------|
| 应用图标 (icon.icns) | ⏳ | 用于 Dock 和应用程序 |
| 托盘图标 (16x16 PNG) | ⏳ | 菜单栏显示 |
| macOS 签名公证 | ⏳ | 需 Apple 开发者账号，否则 Gatekeeper 拦截 |
| 构建测试 | ⏳ | `npm run electron:build` |

**预计工时**: 1 天

---

## 阶段二：体验优化 (P1)

| 任务 | 状态 | 说明 |
|------|------|------|
| 翻译失败重试 | ⏳ | 添加重试按钮 |
| 语言选择 | ⏳ | 当前固定 auto→zh，支持切换目标语言 |
| 开机自启 | ⏳ | `app.setLoginItemSettings` |
| 快捷键自定义 | ⏳ | 当前固定 Alt+Q |

**预计工时**: 2-3 天

---

## 阶段三：功能扩展 (P2)

| 任务 | 状态 | 说明 |
|------|------|------|
| 历史记录 | ⏳ | 数据库已有 `translation_history` 表，UI 待实现 |
| 自动更新 | ⏳ | `electron-updater` |
| Windows 支持 | ⏳ | 当前仅 macOS (screencapture) |

**预计工时**: 1 周
