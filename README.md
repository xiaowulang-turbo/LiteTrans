## 功能特性

- 全局快捷键截图翻译 (默认 Alt+Q)
- 支持 中/英/日/韩 四种语言互译
- 翻译历史记录与云端同步
- 图片预览与复制功能
- 快捷键自定义
- 窗口置顶模式
